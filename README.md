АИС «Умный кампус» (SmartCampus AIS)

Автоматизированная информационная система контроля физического доступа на территорию университета (интеграция со СКУД и мобильными пропусками) и синхронизации учебного расписания.

Технологический стекBackend: .NET 8, C#, ASP.NET Core Web API
База данных: PostgreSQL, Entity Framework Core
Клиент: .NET MAUI (мобильное приложение)
Интеграции: gRPC / HTTP/2 (СКУД), REST API / JSON

Перечень 4 ключевых артефактов проекта

| Тип | Наименование | Формат / Стек | Бизнес-ценность |
